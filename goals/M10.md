# M10 — AI Adaptive Feedback + Open-Response Grading (Cached, Budgeted)

- **Effort tier:** standard
- **Phase:** MVP

## Objective
Add AI that turns the engine's structured "what was wrong" signal into clear, persona-appropriate, localized feedback, and grades open-response items against a rubric — **assistive only**, with caching, tiered models, and budget caps, and the inviolable guardrail that **AI never issues a safety/credential pass**.

## Depends on
- **F5** (the Verdict service's structured "what was wrong" signal — the interface the LLM consumes), **M3** (a branching sim producing fail signals to elaborate). (Also serves M4/M5 sims.)

## Consumes (contracts)
- F5's Verdict structured signal (the deterministic "what was wrong" output — M10 turns it into prose; it does NOT decide pass/fail).
- `academy.assessment_items` (`kind='open_response'`, `is_safety_item`), `academy.assessment_responses` (`graded_by`, `ai_grade_meta`).
- `.env` names: `ANTHROPIC_API_KEY`, `ELEVENLABS_API_KEY`, optional `OPENAI_API_KEY`/`VOYAGE_API_KEY`. R2/KV for caches.

## Tasks (ordered)
1. Build the **`sim-feedback` Edge Function** (server-side; keys never client): input = the Verdict's structured fail signal; output = instructive, persona-appropriate, EN+ES prose. **The engine decides pass/fail (deterministic + safety veto); the LLM only explains** (wave3 §6.1). Fall back to the authored Verdict wording if AI is unavailable/over budget.
2. Build the **`grade-open-response` Edge Function**: score `open_response` items against a rubric/exemplar; return score + rationale; **route a sampled %, plus all near-threshold and all safety-relevant responses, to a human SME** for confirmation. **AI grading never alone issues a safety/egress competency** — those require the sim + Evaluator sign-off regardless (ledger §K, wave3 §6.1).
3. **Cost controls (ledger §K, wave3 §6.2):** aggressive **caching** (R2/KV) of feedback for common failure states + narration + frequent grading — most calls become cache hits; **tiered models** (cheap/fast for routine feedback + first-pass grading, strong only for nuanced grading); **hard token caps per call**; **per-org and per-day budget caps** enforced in the Edge Function with alerts + graceful degradation.
4. **Guardrail tests (the testable invariant, build-readiness §1 M10):** assert the AI path can never set a sign-off `outcome`, promote `competency_state`, issue a credential, or override a safety veto; assert safety-relevant open responses always route to SME.
5. Define concrete **cache-key + model-tier + budget thresholds** (the doc left these unspecified — pin them: cache key on `(item_id|fail_signal_hash, locale, model_tier)`; routine→cheap model; nuanced/tutor→strong model; per-call token cap; per-org/day USD cap with a configurable default).
6. (Optional within budget) ElevenLabs TTS narration generated server-side, **cached in R2** (generate once, serve forever — never per-play).

## Done-criteria (testable)
- AI **feedback explains failures** (instructive, persona-appropriate, EN+ES) from the Verdict signal; falls back to authored wording when AI is off/over budget.
- Open responses are AI-graded with rationale; sampled + near-threshold + **all safety-relevant** responses route to SME.
- **AI never issues a safety pass:** guardrail tests prove the AI path cannot set outcome/promote competency/issue a credential/override a veto.
- Budget caps + caching work: a repeated failure state is a cache hit; per-org/day caps halt calls and degrade gracefully.
- Concrete cache-key/model-tier/budget thresholds are implemented and documented.

## Out of scope
- The deterministic pass/fail + safety veto (F5/M6 own it; AI never decides).
- The RAG "Ask Redex" tutor (Phase 2).
- The full SME review queue UI (a minimal routing flag is enough for MVP).
- Issuing credentials (M7).

## Invariants in play
- Inv. 1 (AI is advisory; deterministic rules + Evaluators hold safety authority; AI never overrides the veto).
- Inv. 2 (AI never writes state tables / issues credentials).
- Inv. 5 (consume F5's Verdict signal; do not let AI become the scorer).
- Secrets: AI keys server-side only.

## Tests required
- **Unit:** feedback generation from a fail signal; grading + SME-routing rules (safety-relevant → always SME); cache-key + budget-cap logic.
- **Guardrail (locked invariant):** AI path cannot set outcome/competency/credential/veto — must stay un-weakened.
- **Integration:** cache hit on repeated failure; budget cap halts + degrades; LLM mocked in CI.
