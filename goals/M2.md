# M2 — MDX Lessons + Retry-to-Mastery Knowledge Checks (EN+ES)

- **Effort tier:** standard
- **Phase:** MVP

## Objective
Render the slice's MDX lessons with embeddable components, and the retry-to-mastery knowledge checks that gate on the **item-level** mastery thresholds (safety items ≥90%, non-safety ≥80%), in EN+ES with the locked safety glossary. Authors the real AC-101/102 2D-interaction specs and AC-202 calculator spec content on the F5b engines.

## Depends on
- **F2** (units/assessment tables + types), **M1** (catalog/enrollment + gating), **S1** (seeded courses/units/assessment_items with `is_safety_item`), **F5b** (the 2D-interaction + calculator engines AC-101/102/202 embed).

## Consumes (contracts)
- `academy.units` (`kind`, `content_ref`), `academy.assessment_items` (`is_safety_item`, `kind`, `mastery_weight`), `academy.assessment_responses` (`client_event_uuid`, retry `attempt`).
- F5b engines (`two_d_interaction`, `calculator`) + `packages/sim-schemas`; F5's Verdict service.
- `packages/i18n` (EN+ES, locked safety glossary).

## Tasks (ordered)
1. Define the **MDX component contract** (build-readiness review §1 M2 gap): the embeddable components an MDX lesson may use — `<Sim/>` (loads a `sim_definition` by key/kind, incl. the F5b 2D + calculator engines), `<KnowledgeCheck/>` (renders `assessment_items` with retry), `<Checklist/>`, `<Callout/>` (safety call-outs), `<Media/>` (R2/Stream refs). Publish it in `packages/ui`.
2. Build the **MDX renderer** in `apps/web` reading `units.content_ref`; render the slice's Foundations + AC lessons (`FND-101/102/103`, `AC-101/102/103`, plus `INT-101/102`, `ADC-101/102/201` lesson bodies as content slots).
3. Author the **AC-101 / AC-102 2D-interaction specs** (anatomy-of-a-door drag-label + access-event ordering; "Spec the Door" matcher) and the **AC-202 calculator spec** ("will it hold"/PoE budget) as `sim_definitions` validated against the F5b schemas. (Content authored to the bible; safety-adjacent fail-safe/fail-locked items flagged.)
4. Implement **retry-to-mastery knowledge checks**: multiple `attempt`s, scored against item-level thresholds — **safety items ≥90%, non-safety ≥80%** (ledger §C; the per-competency scalar is insufficient). Gating reads `is_safety_item`. Responses append-only with `client_event_uuid` (offline-tolerant via F4).
5. Wire **EN+ES i18n** for all slice strings; the **locked safety glossary** (fail-safe/fail-locked, REX, egress, PPF, partition) reads identically across languages and is non-overridable.
6. Mastery state is computed server-side (mastery verdict is server-only per ledger §G); the client renders pass/retry but does not self-promote `competency_state`.

## Done-criteria (testable)
- `FND-101/102/103` and `AC-101/102/103` render via MDX with embedded checks; AC-101/102 load their 2D-interaction sims and AC-202 loads its calculator sim.
- **Mastery gate:** a knowledge check with safety items requires **≥90% on safety items** and ≥80% on non-safety to pass; below-threshold prompts retry; the gate reads `is_safety_item` (not a single per-competency scalar).
- EN and ES render for all slice strings; switching locale keeps safety-glossary terms identical.
- Responses queue offline and reconcile (with F4); replays are idempotent.
- Mastery verdict is computed server-side; the client cannot set `competency_state`.

## Out of scope
- Branching/device-config/WebGL sims (M3/M4/M5) — M2 embeds only the F5b 2D + calculator engines and renders lessons.
- Field sign-off (M6), badges (M7), AI feedback (M10), authoring UI (M9).
- Tagalog (Phase 2; slice is EN+ES).

## Invariants in play
- Inv. 1 / Inv. (ledger §C): item-level mastery thresholds (safety ≥90%, non-safety ≥80%).
- Inv. 2 (mastery verdict server-only; client never writes `competency_state`).
- Inv. 4 (responses append-only, `client_event_uuid`, offline-tolerant).
- Inv. 7 (a11y, colorblind-safe, EN+ES, locked glossary).

## Tests required
- **Unit:** mastery-threshold gating (safety ≥90% vs non-safety ≥80%); retry logic; the MDX component contract.
- **e2e (Playwright):** render a lesson, fail a safety check at 85% (blocked), pass at 95%; locale toggle EN↔ES.
- **offline:** complete a check offline, reconcile.
- **a11y:** lessons + checks pass axe; keyboard-navigable; no color-only state.
