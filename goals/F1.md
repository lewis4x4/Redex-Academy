# F1 — Repo + CI/CD + Monorepo + Env Scaffolding

- **Effort tier:** standard
- **Phase:** 0 (Foundation)

## Objective
Stand up the pnpm + Turborepo monorepo skeleton, the package/app boundaries, CI gates, Netlify preview deploys, and the complete `.env.example` (names only) — so every later goal builds inside a fixed workspace graph instead of inventing one. No feature code.

## Depends on
- Accounts/services provisioned by Brian (Phase 0, human): GitHub repo, Supabase project, Cloudflare (R2/KV/D1/Stream/Workers), Netlify site, LRS host, IdP, AI providers. F1 does **not** create accounts or paste real secret values.

## Consumes (contracts)
- None (this goal **produces** the foundational contracts: workspace graph, `turbo.json` pipeline, CI required-checks set, `.env.example`).

## Tasks (ordered)
1. Init pnpm workspace at repo root: `pnpm-workspace.yaml`, root `package.json`, `.npmrc`, Node + pnpm version pins (`.nvmrc`, `packageManager`). Pin **TypeScript strict** everywhere.
2. Create `turbo.json` with pipeline tasks: `build`, `dev`, `lint`, `typecheck`, `test`, `test:e2e`, `test:a11y`, `gen:types` (with correct `dependsOn` topology and cache outputs).
3. Create the workspace packages/apps (folders + `package.json` + `tsconfig.json` extending a shared base; stub `index.ts` where needed):
   - `apps/web` — the learner PWA (Vite + React 18 + TS + Tailwind). Bootstrap a Vite app shell only.
   - `apps/admin` — authoring admin (Vite + React + TS). Stub shell only.
   - `packages/db-types` — **committed** generated Supabase types land here (`database.types.ts`). Stub + export placeholder until F2.
   - `packages/sim-schemas` — JSON Schemas + Zod for sim specs (filled by F5/F5b).
   - `packages/sim-engine` — the Forge runtime + Verdict service (filled by F5/F5b).
   - `packages/ui` — shared component library (colorblind-safe primitives, a11y baseline).
   - `packages/i18n` — react-i18next config + locale JSON + the locked safety glossary table.
   - `packages/config` — shared ESLint, Prettier, tsconfig-base, tailwind preset.
   - `supabase/` — `config.toml`, `migrations/`, `functions/` (Edge Functions, Deno), `seed/`.
   - `workers/` — Cloudflare Workers (Wrangler) for credential verify / fixture serving (filled by F6/F5).
   - `infra/` — scripts (DAG-check, typegen-drift check).
4. Wire shared tooling: ESLint + Prettier + Husky + lint-staged (pre-commit: lint-staged; pre-push: typecheck). Add `commitlint` optional.
5. Add the **CI required-checks set** as a GitHub Actions workflow (`.github/workflows/ci.yml`) running on PR; each is a merge-blocking job: `typecheck`, `lint`, `unit` (Vitest), `e2e` (Playwright, incl. an offline-path smoke once F4 exists — stub job now), `a11y` (axe), `rls-negative` (stub now; real in F2), `dag-check`, `typegen-drift` (fails if `supabase gen types` output differs from committed `db-types`), `sanitized-fixture` publish-gate (stub now; real in F5).
6. Author `infra/dag-check.ts` (queries `course_prerequisites` for cycles via the committed types/DB; safe no-op + clear "no schema yet" exit until F2) and `infra/typegen-drift.ts`.
7. Write the canonical `.env.example` with **names only**, matching ledger §A corrections:
   - Keep all client-public `VITE_*` and all server-only secrets from Build Sequencing §2.2.
   - **DELETE** `REDEX_WORKOS_DB_URL`, `REDEX_WORKOS_API_URL`, `REDEX_WORKOS_SERVICE_KEY` (one shared project; federation creds are wrong + a needless secret-leak surface).
   - Add a comment block stating: one Supabase project, two schemas (`academy`, `workos`), shared `auth.users`; secrets live in `.env.local`/Netlify env/Supabase Vault/CF Secrets only.
8. Configure Netlify: `netlify.toml` building `apps/web`, PR preview deploys, SPA + PWA headers (no-cache on the service worker, long-cache on hashed assets), instant rollback. Document env wiring in Netlify (names only).
9. Author `CLAUDE.md` at repo root with the full §3 checklist from the build-readiness review: north star (competency engine, NOT an LMS; See-one/Do-one/Prove-one → signed credential; "slides-and-quiz is banned"), exact monorepo layout, pinned stack majors, canonical commands, the **8 inviolable invariants** (GOALS_INDEX cross-cutting list), the contract-first rule, ultracode triggers, the human-gate list, the DoD template, secrets rule, i18n/a11y conventions, naming conventions (course codes are canonical IDs; persona vs role separation).

## Done-criteria (testable)
- `pnpm install` succeeds; `pnpm build`, `pnpm typecheck`, `pnpm lint` pass on the empty skeleton.
- `turbo run build` resolves the package graph with no cycle/topology errors.
- A trivial PR triggers GitHub Actions; all required-check jobs run and the merge is blocked if any fail.
- Netlify produces a **preview deploy URL** for the PR; the PWA shell loads.
- `.env.example` contains every name from Build Sequencing §2.2 **minus** the three `REDEX_WORKOS_*` vars; no real secret values anywhere in the repo.
- `CLAUDE.md` exists with all checklist sections.
- `dag-check` and `typegen-drift` scripts run (no-op cleanly pre-F2).

## Out of scope
- Any DB schema, RLS, auth, sim engine, or feature code. (Stubs only where a package must export a placeholder.)
- Creating cloud accounts or writing real secret values.
- Lovable integration — the admin is built in-repo directly (treat Lovable as out of scope).

## Invariants in play
- Inv. 5 (contract-first): F1 establishes the workspace + CI so later goals can never silently invent the layout.
- Inv. 8 (migration→typegen): CI `typegen-drift` job is created here; the rule is documented in `CLAUDE.md`.
- Secrets discipline: names-only `.env.example`; `VITE_`-prefixed only for client-public.

## Tests required
- **Unit:** a smoke test in `apps/web` and one shared package, proving Vitest + the workspace resolve.
- **CI self-test:** the workflow passes on the skeleton and fails fast on an intentionally broken type (verify the gate works).
- **a11y:** axe runs (vacuously) on the app shell route.
